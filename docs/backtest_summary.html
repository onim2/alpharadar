01

분석 개요

대상 시스템과 데이터, 검증 방법

AlphaRadar v3.3은 한국 주식 스캐너로, 종합점수를 S = T×0.30 + S_text×0.40 + D×0.30 (기술·감성·수급)으로 산출한다. 검증에는 GitHub Actions로 매일 자동 수집된 라이브 DB를 사용했다(백필 아님 → 뉴스 lookahead 편향 최소). 성과는 절대수익이 아니라 시장중립 지표인 IC(Information Coefficient, Spearman 순위상관)와 Decile 단조성으로 판단한다 — 전 구간이 하락장이라 절대수익은 시장 영향이 지배적이기 때문이다.

해석 프레임 IC ≥ 0.05 유의미 / 0.02–0.05 약함 / <0.02 신호 없음. 등급은 집중 27 · 주시 137 · 참고 4,184건.

05

리스크 필터 검증 — 강호재+과열 제외

"positive 뉴스 + 이격 과열" 종목을 빼면 개선되는가?

  • 전제는 맞음 — 넓은 유니버스에서 제외 대상(s_text≥70 & disparity≥115)은 10일 승률 0.0%(55건 전멸)로 확실히 독성.
  • 그러나 포트폴리오 효과 미미 — 대상이 4,500건 중 55–119건뿐. 전체 ΔIC = +0.005~0.007, Δ평균 +0.1%p 수준. IC≈0을 못 고침.
  • 정작 실행 등급(집중+주시)에선 역효과 — 제외한 35건은 동료 대비 더 나쁘지 않았다(5일 −3.0% vs 전체 −9.1%). 빼면 실행 성과가 오히려 하락.

06

Walk-forward 검증 — 과최적화 확정

시간순 train/test 분할: 과거에서 찾은 최적 가중치가 미래에도 통하는가?

종합 결론 & 권고

  • 현 국면에서 종합 스코어의 IC는 사실상 0 — 없는 알파는 가중치·필터로 만들 수 없다.
  • 뉴스 감성(news_score)이 IC를 −0.08까지 끌어내리는 핵심 드래그. 공시(dart)는 무해.
  • 그리드서치 최적해는 과최적화 확정 — walk-forward에서 IS +0.037 → OOS −0.075로 붕괴. 가중치 튜닝으론 실전 우위 못 만듦.
  • 모든 근거는 단일 하락국면(약 2개월) · |IC|<0.05로 통계적 신뢰도가 낮다.
핵심 메시지 혼란장 대응의 실질 지렛대는 신호 재튜닝이 아니라 노출(포지션) 축소다. 신호 품질이 낮은 국면엔 베팅 자체를 줄이는 것이 맞다.
